# Robot Arm Mounted Wheelchair

## Overview

This project focuses on the development of an autonomous wheelchair platform with a mounted robotic arm for assistive robotic application.

## Features

- ROS2-based control architecture
- Autonomous translational and rotational movement
- Closed-loop motor control using RoboClaw motor controllers
- Encoder-based position and velocity feedback
- Custom wheelchair control system replacing OEM controller

## Hardware

- RoboClaw Motor Controller
- Rotary Encoders
- Raspberry Pi

## Software

- ROS2
- Python
- Ubuntu Linux

## Status

Implemented:
- Motor controller integration
- Encoder feedback processing
- Translational motion control
- Combined translational and rotational motion control
- ROS2 nodes for wheelchair motion commands
